# @sheleg-design/orchard

The React reference kit for the SHELEG **Orchard** style pack — friendly consumer
biotech and DTC wellness: a warm oat field carrying a stack of rounded slabs, a
sage-green brand, and one candy orange reserved entirely for the action.

It is generated from the pack, not authored beside it: `src/styles.css` opens with
`styles/tokens/orchard.css` byte for byte, and the rules the design agent must obey
are in [`.design-sync/conventions.md`](./.design-sync/conventions.md).

```bash
npm install && npm run build
```

Then run `/design-sync` in Claude Code from this directory to push it to
claude.ai/design.
