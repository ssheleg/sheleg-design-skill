Square, hairline, mono at `--fs-micro` tracked `--track-label`, uppercase. `accent` fills
it with the orange, and at that point the label must be treated as non-text — it is
3.02:1 and it is there to be recognised by shape and position, with the word repeated in
the row beside it.

For a severity chip use `Guardrail`, which enforces the word.

```tsx
<Chip>Revenue Ops</Chip>
<Chip selected>Deal Desk</Chip>
```
