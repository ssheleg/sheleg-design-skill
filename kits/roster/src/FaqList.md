A `<dl>`, always open, hairline between rows. The reference animates its accordion
over 0.7s (`--dur-accordion`); this component does not collapse at all, because an
answer a crawler cannot read without running JavaScript is an answer that is not
there.

```tsx
<FaqList entries={[{ q: 'Does it work for local SEO?', a: 'Yes.' }]} />
```
