A 1px `--rule` line, and the only divider this pack has. `strong` exists for the
one heavier edge a footer sometimes needs.

There is no shadow anywhere on this pack, so the rule does all the separating that
elevation does elsewhere. Use it sparingly: on cream paper at this measure, white
space already divides, and a page ruled at every boundary reads as a table.

```tsx
<Rule />
<Rule tone="strong" />
```
