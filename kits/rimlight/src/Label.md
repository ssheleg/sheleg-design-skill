The monospace, uppercase, at `--t-label` (16px) and `--weight-label` (500). It carries
every nav item, every button and every section eyebrow — the grotesque carries only
sentences, and that split is the pack's most legible rule.

**Do not track it.** `letter-spacing` computes to `normal` on every label in the
reference; the openness is Source Code Pro's own advance width. Adding tracking is the
trap this pack sets for anyone matching it from a screenshot.

```tsx
<Label>Services</Label>
<Label role="eyebrow">How we measure success</Label>
```
