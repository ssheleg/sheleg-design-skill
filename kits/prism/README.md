# @sheleg-design/prism

The React reference kit for the SHELEG **Prism** style pack — one static iridescent wash with a hard bottom edge, a heavy grotesque display over mono body copy.

It is generated from the pack, not authored beside it: `src/styles.css` opens
with `styles/tokens/prism.css` byte for byte, and the rules the design agent
must obey are in [`.design-sync/conventions.md`](./.design-sync/conventions.md).

```bash
npm install && npm run build
```

Then run `/design-sync` in Claude Code from this directory to push it to
claude.ai/design.
