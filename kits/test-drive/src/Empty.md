An empty screen is a state, not an absence: a `--surface` card holding one 16px/500
line, one sentence in `--ink-mute`, and one quiet control that starts the demo — this
pack always has a demo to offer. A zero in a metric renders as a figure in its tile,
the way the reference's dashboard ships "Online 0".

```tsx
<Empty title="No data yet" hint="Add your website to start the tour."
  action={<Button variant="secondary">Try the live demo</Button>} />
```
