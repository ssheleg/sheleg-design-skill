# @sheleg-design/instrument-console

The React reference kit for the SHELEG **Instrument Console** style pack — a
near-black aerospace console (one dark register, no light twin) for technical,
systems, infra and "operating system" products.

It is generated from the pack, not authored beside it: `src/styles.css` opens with
`styles/tokens/instrument-console.css` byte for byte, and the rules the design agent
must obey are in [`.design-sync/conventions.md`](./.design-sync/conventions.md).

```bash
npm install && npm run build
```

Then run `/design-sync` in Claude Code from this directory to push it to
claude.ai/design.
