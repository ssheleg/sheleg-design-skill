A readout, not a poster figure: a tracked-out mono eyebrow, a large tabular
`--font-data` value, and an optional `source` line under it. Every label that
narrates system state is mono in this pack, and that is why the label sits in the
data face rather than the UI one. Name the window and the origin in `source` —
"last 24h · p95, all regions" — because a figure whose window is unstated is a
figure nobody can act on. The tile is a `--surface-2` step inside a hairline; the
value stays `--ink` and never borrows the accent.

```tsx
<Stat value="128 ms" label="P95 LATENCY" source="last 24h · all regions" />
<Stat value="99.982%" label="LINK UPTIME" source="rolling 30d · downlink LINK-04" />
```
