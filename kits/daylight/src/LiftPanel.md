**The one object per view that lifts off the field**, on `--shadow-lift` — 90px
of blur at a −30px spread. It is a budget rather than a style: the page is
remembered as *the one where that thing floats*, and a second use leaves the
memory with nothing to attach to.

Default every other surface to `Card`, which carries the quiet `--shadow-1`, and
make this one opt-in.

```tsx
<LiftPanel><ProductRecord /></LiftPanel>
```
